# 디자인 검증 오류 수정 — 2026-09-07

## 수정 범위

- iOS 검사: 이미지 변경/캡처 누락/기준 누락을 별도 집계하고 실패 시 manifest와 decision log에도 실제 원인을 기록한다. 기준 갱신은 검토한 캡처만 복사하며 재촬영하지 않는다.
- 웹: 공통 토큰 CSS를 생성·복사·검증하고 웹이 이를 import한다. 기존 10/11/13px 글꼴, 20px 모서리와 크기/색상 직접 지정을 토큰으로 치환했다. 기존 반응형 비율과 hero 높이는 의미가 명확한 web 전용 토큰으로 유지했다.
- iOS 피드: 이미 반영된 디자인 개편에 맞춰 계약의 heading 요구를 mainTabHeader로 수정했다. 검사를 위해 화면 글자 크기를 바꾸지 않았다.
- iOS 실제 결함: 시각 테스트의 차단 상태 조회가 서버 인증 요청으로 이어지는 문제를 fixture로 차단했다. iOS 26 기본 탭 바 중복 표시를 막고 사용자 정의 탭 바를 별도 레이아웃 행으로 배치해 대화 입력창이 가려지지 않게 했다. 시각 테스트에서 알림 권한 팝업을 요청하지 않는다.
- 웹 시각 검사: 삭제된 메시지/마이페이지 주소의 홈 리다이렉트와 점검 화면을 잘못 촬영하던 검사를 현재 공개 홈과 게시글 상세로 갱신했다. 테스트 브라우저에 한해서 점검 게이트를 해제하고, 내용·주소·폰트 로딩과 reduced motion을 확인한다.

## 검증 결과

- `npm run verify-design-system:full`: 종료 코드 0. 토큰/계약/생성물 검사, 웹 화면 6개, iOS 화면 4개 통과.
- 검사 스크립트 회귀 테스트: 6개 통과. 변경 전 스크립트에서는 기존 오류를 겨냥한 3개 테스트가 실패하는 것도 확인했다.
- 웹: 130개 테스트 통과, TypeScript/Vite 빌드 통과. 현재 공개 화면을 변경 전 코드로도 빌드하여 비교했다. 홈의 작은 글꼴 렌더링 차이는 기존 허용 범위 내였고 게시글 화면은 동일했다.
- iOS: 129개 테스트 통과, generic iOS Simulator 빌드 통과. 스플래시 8개 크기 × light/dark = 16개 조합 포함.
- Android: `:app:assembleDebug` 통과. 추가 토큰은 자동 생성된 선언이며 기존 Android 화면은 이 신규 토큰을 사용하지 않는다.
- iOS 기준: iPhone 15 / iOS 26.0, 1179×2556, light, Large, ko_KR, Asia/Seoul, 상태바 9:41. 검토한 기준을 저장한 뒤 앱을 다시 빌드·실행·촬영하여 통과했다.
- 반복 캡처의 뒤로가기 아이콘 가장자리 69픽셀에서 RGB 각 1단계의 반올림 차이만 관측됐다. 총 채널 차이 3만 허용하고 변경 픽셀 비율 허용치는 0을 유지한다. 실제 이미지 변경은 회귀 테스트에서 계속 실패한다.

## 검증 범위와 보존 사항

- cross-platform parity는 기존 `report` 모드다. 과거 웹 앱 스크린샷과 최신 iOS 사이의 차이 4개를 여전히 기록하며, 플랫폼 간 디자인이 동일하다고 판정한 것은 아니다. 현재 공개 웹과 네이티브 앱은 화면 구성이 다르다.
- 삭제된 웹 메시지·마이페이지 라우트는 복구하지 않았다. 남아 있는 컴포넌트는 토큰 검사와 기존 컴포넌트 테스트 대상으로 유지한다.
- 작업 시작 전에 수정되어 있던 웹 스크린샷 11개는 덮어쓰거나 이번 커밋에 포함하지 않는다. 새 공개 화면 기준은 landing/post 이름으로 별도 저장했다.
- GitHub Actions의 결제·사용 한도와 배포 설정은 이번 수정 대상에서 제외했다.
