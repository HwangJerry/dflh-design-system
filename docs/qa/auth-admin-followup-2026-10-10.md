## 연결 해제 후 신규 가입의 정책 경계

회원 12822의 카카오 연결을 해제하고 기존 회원을 유지한 상태에서는 가입 화면에 진입했지만 최종 제출이 409와 “이미 다른 계정에 연결된 소셜 계정입니다. 다시 로그인해주세요.”로 거부됐다. 새로운 회원은 생성되지 않았다.

코드의 `relinkSocialIdentityTx`는 REVOKED identity의 소유권을 유지하고 동일 회원의 명시적 재연동만 허용한다. 가입은 더 엄격하게 중복을 차단한다. 관찰 초기에 추가 결함이라고 언급했으나, 코드 확인 후 중복 방지 정책으로 정정했다. 식별자를 임의로 다른 회원에게 이전하지 않았다. 사용자에게 이미 허용된 QA 회원 탈퇴 절차로 12822를 삭제한 다음 같은 카카오 계정의 신규 가입이 성공했다.

해제된 소셜 계정의 신규 가입이 허용되지 않는데 입력 마지막 단계에서야 거절되는 점은 UX 개선 검토 사항이다. 이를 해소하려면 소유권 정책을 유지한 채 가입 시작 단계에서 기존 회원 로그인·재연동을 안내하는 방안을 별도로 결정해야 한다.

## 최종 삭제 상태와 제한

최종 조회에서 회원 12822·12823·12825의 WEO_MEMBER, AUTH_IDENTITY, ALUMNI_MOBILE_REFRESH_TOKEN은 각각 합계 0건이다. 카카오 회원 12825의 WEO_MEMBER_SOCIAL과 ALUMNI_SOCIAL_CREDENTIAL도 0건이다. 요청 23은 cancelled이고, 요청 24·25·26은 processing/database_erased이다. 백업·복원 방지, 외부 서비스·로그, 과거 파일 검증은 complete이고 SMS 인증 기록 정리가 남았다. 제공자 해제가 선행된 뒤 DB 삭제가 실행되는 순서도 확인했다.

| 요청 | 대상 회원 | 남은 SMS 기록 | 정리 예상 시각(KST) |
| --- | --- | --- | --- |
| 24 | Native 신규 QA 12823 | 4건 | 2026-10-11 01:47:13 |
| 25 | 기존 Android QA 12822 | 5건 | 2026-10-10 04:03:02 |
| 26 | 카카오 신규 QA 12825 | 3건 | 2026-10-11 01:36:29 |

전화번호 기반으로 조회하는 보관 대기 기록은 요청 간 겹칠 수 있어 합산하지 않는다. 같은 전화번호의 추가 QA 인증으로 예상 시각이 갱신될 수 있다. 예상 시각 이후 정상 cleanup/worker 실행과 completed·COMPLETED_AT을 추가 확인해야 한다. 전화 인증 기록의 24시간 보관과 재검증을 기다리는 요청은 completed로 표현하지 않는다. 관리자에서 완료 상태를 강제 설정하지 않았다.

기기 처리 현황은 “아직 완료가 아닙니다”, “앱 운영 데이터 삭제 후 남은 작업을 확인 중입니다. 모두 끝나면 완료로 표시됩니다.”라고 표시했다. 실제 DB 삭제와 전체 처리 완료를 구분했다. 최종 기기는 로그아웃 상태다.

전화 인증은 사용자 지시대로 임시 Android 테스트번호와 기존 고정 QA 코드를 사용했다. 실제 SMS 전달 검수는 포함하지 않는다. 테스트번호 추가 설정은 원래 `SMS_REVIEW_TEST_PHONES` 문자열로 복구했고 기존 코드도 정확히 유지되는지 확인했다. 재시작한 서버의 바이너리 SHA는 기존 배포와 같고 앱·관리자 health는 모두 200이다.

root 회원 12813 및 root 권한과 iOS QA 회원 12820은 보존했다. 기존 Android QA 회원 12822는 신규 가입 검수를 위한 탈퇴 주기에 따라 삭제했다. 다른 회원의 요청 10은 처리하지 않았다.

승인 대기 화면에서 표시되는 `USR_STATUS=BBB`와 별개로 동문 인증은 `ALUMNI_VERIFICATION.STATUS=approved`가 접근 권한을 결정한다. 관리자 승인 이후 정상 화면 진입과 인증 상태를 함께 확인했다.
